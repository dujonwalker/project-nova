# Legacy Project NOVA material

This directory preserves the pre-v2 Project NOVA implementation for
historical reference and migration work. It contains the former n8n,
OpenWebUI, router-agent, prompt-template, screenshot, and retired MCP server
surfaces.

Nothing in this directory is part of the active v2 architecture. New
capabilities belong under the root `mcp-server-dockerfiles/` directory and
should follow the client-agnostic Streamable HTTP model described in the root
README.
