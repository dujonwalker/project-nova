# RAGFlow MCP Server (Streamable HTTP)

Powered by [xiangmy21/ragflow_mcp_server](https://github.com/xiangmy21/ragflow_mcp_server) running native Python `StreamableHTTPSessionManager` at `/mcp`.

## Endpoint
- **MCP Endpoint**: `http://<HOST_IP>:3015/mcp`
- **Healthcheck**: `http://<HOST_IP>:3015/health`
- Pure Python runtime — no Node.js or third-party proxy gateways
