Most bundle names match the corresponding server directory under
[`mcp-server-dockerfiles/`](../mcp-server-dockerfiles/). The intentional
aliases are:

- `ableton-mcp` → `ableton-copilot-mcp`
- `blinko-mcp` → `custom-blinko-mcp`
- `fetcher-mcp` → `fetch-mcp`
- `mcp-shell` → `cli-server-mcp`
- `searxng-research` → `searxng-mcp`
- `vision-bridge` → `vision-bridge-mcp`

Open a bundle's `SKILL.md` for its capability guidance and references.
