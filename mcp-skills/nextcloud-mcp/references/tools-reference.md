# `nextcloud-mcp` Tools Reference

Tool availability reflects installed Nextcloud apps (`APP_CAPABILITY_KEY` gates `notes`, `tables`, `deck`, `cookbook`, and `talk` / `spreed`), `--enable-app` filtering, and optional features.
